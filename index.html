Install the Moto Buttons app

It updates the controller's firmware over Bluetooth. It is not in Google Play, so Android asks a few questions while installing.

Download the app
  1. When the download finishes, tap Open (or open moto-buttons.apk from Downloads).
  2. If Android says Chrome is not allowed to install apps, tap Settings, switch on Allow from this source, then go back.
  3. Tap Install. If Google Play Protect warns about an unknown app, tap More details > Install anyway.
  4. When it is installed, come back to this page.

DMD2 support

I use DMD2 and want the controller to work as a DMD Remote.

DMD2 reads the controller through THORK Racing's free DMD Manage app. Download it from their page:

Get DMD Manage
  1. On THORK's page, download the Manage app and install it the same way (Open > Install > if warned, Install anyway).
  2. The Moto Buttons app then shows how to switch it on (Accessibility), including Android's Allow restricted settings step.

Update the controller

Switch the controller on. The app finds it, checks its firmware and offers the update when a new version is out.

Open Moto Buttons
  1. Not paired yet? In the phone's Bluetooth settings tap Scan, tap DMD-Remote3, then Pair.
  2. In the app, tap Update and keep the controller powered for about a minute and a half.
  3. When it says All set, you can remove the app again; the controller keeps working.
Updates over Bluetooth need firmware 2.2.0 or newer on the controller. Older controllers are updated once by USB.
Moto Buttons is an open-source handlebar controller. DMD Manage and DMD2 belong to THORK Racing and are downloaded from their site.
